# Метки триажа

Навыки оперируют пятью каноническими ролями триажа. Этот файл сопоставляет роли с реальными строками меток в трекере этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                       |
| ------------------------- | --------------------- | ---------------------------------------------- |
| `needs-triage`            | `needs-triage`        | Мейнтейнеру нужно оценить задачу               |
| `needs-info`              | `needs-info`          | Ждём от автора дополнительную информацию       |
| `ready-for-agent`         | `ready-for-agent`     | Полностью описана, готова для агента без надзора |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком                   |
| `wontfix`                 | `wontfix`             | Делать не будем                                |

Когда навык упоминает роль (например, «поставь метку готовности для AFK-агента»), используй соответствующую строку метки из этой таблицы.

Чтобы использовать другие названия, поменяй колонку «Метка в нашем трекере».
